## 功能

- 🔴 **未回關高亮**：跟隨中頁，沒回關你的帳號用紅框圈起來
- 🔴 **未回跟高亮**：跟隨者頁，你沒回追的帳號用紅框圈起來
- 🏷️ **每列狀態標籤**：`互關`／`未回關 · 已監測 N 天`／`已回跟`／`未回跟`（全中文）
- 📊 **即時統計面板**：`未回關 N`／`總共 M · 互關 K`，不重複累計、只增不減
- 📋 **點數字看完整名單**（v6.10，v6.11 加上顯示名，v6.12 修復，v6.13 重寫抓取邏輯徹底解決頭像連結擋路）：點面板上的 `未回關 / 未回跟` 數字 → 彈出完整名單視窗，每列顯示 `顯示名稱 + @帳號 + 已監測天數`（越久沒回你的排越前），可點帳號直接開主頁、可一鍵複製成純文字。**名字讓你不必再從 ID 猜是誰**；抓不到名字時只顯示 `@帳號`，不影響功能。解決 X 虛擬捲動「滑不完、數不出來」的問題
- 📅 **首次發現追蹤**：自動記錄每個未回關帳號第一次被發現的日期
- ⬆️ **智能排序**：未互關排最前、已互關排最後；只在列表頂部＋靜止時重排，捲動期間完全不碰 DOM（不卡頓、不空白）
- 🚫 **封鎖校正**：你拉黑某人後，自動把他從統計中剔除
- 👥 **逛別人的列表**（v6.9）：點進別人的 `/followers` 找人關注時，自動切成另一套口徑——**不出現「未回跟」也不畫紅框**（那些人本來就不是你的粉絲），只標綠色 `關注了你`（值得回關）／`已追蹤`（別重複點）／`互關`；沒追你也沒被你追的一律不標。面板顯示 `關注你 N · 總共 M · 已追蹤 K · 他人列表`，排序把「關注了你」的人排最前
- 🧹 **推薦帳號排除**（v6.8，僅自己的列表）：X 在跟隨者列表尾端插入的「為你推薦／你可能感興趣／Who to follow」區塊不是你的粉絲，標灰色 `推薦 · 非粉絲`，不打紅框、不計入未回跟
- 🕵️ **本地取關偵測**：自動記下誰偷偷取消追蹤你，該列標 `剛取關你`／`曾取關 · 9/9`；點面板上的 `取關` 那行可看名單與功能說明（0 筆時會直接解釋這功能在做什麼）。資料只存自己的瀏覽器，不公開、不上傳
- 🟡 **我取關過標記（v6.14+）**：自動記下你**主動取消追蹤**過的帳號（本機 `xufr_i_unfollowed_v1`），避免你之後又手滑關注回去。打開該帳號的**個人主頁**（x.com/帳號）時，頭像下方的名字＋暱稱旁會出現琥珀色小膠囊「提醒：你曾在 M/D 取關過 @帳號」。點擊「取消追蹤」按鈕時才記錄（取消對話框不記、X 虛擬列表把同一格複用完給別人時不記錯人 → 零誤報）。**只顯示在主頁，不顯示在雷達列表／面板**；資料只存自己瀏覽器，不公開、不上傳

## 安裝

1. 瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/)
2. 打開 `GANSHA-Mutual-Radar.user.js` 的 Raw 頁面，或複製原始碼新增腳本
3. 到 `https://x.com/` 的 **跟隨中** / **跟隨者** 頁即可看到效果

## 使用

- 進 `/following`：未回關（他沒回關你）的排最前，紅框＋標籤標示
- 進 `/followers`：未回跟（你沒回追他）的排最前，紅框＋標籤標示；X 自己塞進來的推薦帳號標 `推薦 · 非粉絲`，不計入
- 進**別人的** `/followers`：不畫紅框，只標 `關注了你`／`已追蹤`／`互關`，「關注了你」的人排最前
- 進**任意個人主頁**（x.com/帳號）：若你曾主動取關過他，頭像下方的名字＋暱稱旁會出現琥珀色膠囊「提醒：你曾在 M/D 取關過 @帳號」，防止你又跟回去（只在此處顯示）
- 往下捲載入更多 → 捲回頂部時會自動重新集中排序
- 右下角面板顯示累計統計與品牌標識
- 面板點 `未回關 / 未回跟` 的數字 → 彈出完整名單；點 `取關` 那行 → 看取關名單與功能說明（見下方章節）

## 本地取關偵測（v6.6+）

想知道「誰偷偷取消追蹤我」，不用一個一個點進去看，也不用把帳號交給任何第三方 App。

**怎麼做到的**

腳本每次掃描都記下「這個人當時有沒有追你」，下次再掃到同一個人時比對：

- 上次 **有追你** → 這次 **沒追你**，且「沒追你」的狀態**連續超過 30 分鐘** → 判定被取關
- 該列標上紅底白字 `剛取關你`（當天新偵測）或 `曾取關 · 9/9`（之前記過，附日期）
- 面板多一行 `取關 N`（0 筆時顯示「還在觀察中」），點一下彈出取關名單與功能說明；名單也可在 Console 執行 `__ganshaExportUnfollowers()` 取得

**為什麼要等 30 分鐘**

X 的「跟隨你」指示器是**分批渲染**的，列表剛載入時常常暫時讀不到。若當下就判定，會出現大量誤判——你會去質問一個其實沒取關你的人。30 分鐘寬限讓 DOM 載完後自動回補，誤判自己消失。

**已知限制**

- 屬**增量累積**：同一個人要被掃到兩次以上才會有紀錄；沒捲過、沒載入到的帳號不會計入
- 第一次掃到某人時只建立基準，當下無法判斷他是否剛取關
- 只偵測「他取消追蹤你」（跟隨中頁），不偵測你自己的主動操作

**隱私與合規**

- 資料全部存在**你自己的瀏覽器 localStorage**（`xufr_mstate_v1`、`xufr_unf_v1`、`xufr_names_v1`、`xufr_i_unfollowed_v1`），**不公開、不上傳、不傳送給任何人**
- 純讀取自己頁面上已顯示的公開資訊，**無 API 呼叫、無自動追蹤／取消追蹤**
- ⚠️ 請勿把偵測結果整理成公開名單發布。號召集體標記特定帳號違反 X 的 targeted harassment 與 platform manipulation 規則，且實務上被處分的往往是發起者，不是被點名者

## 更新

腳本頭部已設定更新來源（`@updateURL` / `@downloadURL` 指向 repo 的 Raw 網址）。

- **從 Raw 網址安裝**：Tampermonkey 會定期自動檢查，有新版時圖示出現紅色數字 → 點開按「**更新**」即可，不用重裝。**舊版也適用**——油猴會記住安裝時的網址並持續拿它對版本，不需要腳本本身寫過 `@updateURL`
- **手動檢查**：Tampermonkey 圖示 → 控制台 → 「已安裝腳本」分頁 → 上方「**檢查更新**」
- **核對目前版本**：右下角面板頁腳 `𝕏 @todaygansha · v6.15`，或 Console 的 `[GANSHA 雷達] v6.15 已載入`
- 早期用「手動複製貼上／別人傳檔案」方式安裝的人**沒有可回頭查的網址、不會自動更新**——走一次 Raw 網址安裝（會顯示「重新安裝」，按下去）即可接上自動更新。累積的觀察紀錄（`xufr_mstate_v1`、`xufr_unf_v1`、`xufr_names_v1`、`xufr_i_unfollowed_v1`）**不會被蓋掉**

> 給改版的人：每次發版**務必把 `@version` 往上加**，否則油猴不會判定為新版。
> 另外 `raw.githubusercontent.com` 有 CDN 快取（通常數分鐘），剛推送完馬上檢查可能仍讀到舊版。
