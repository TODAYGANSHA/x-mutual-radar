# 𝕏 GANSHA Mutual Radar（GANSHA 互關雷達）

> 目前版本：**v6.9**

X (Twitter) 油猴腳本：一眼看出誰沒回關你，把「未互關」的帳號集中到列表最前面。

純前端顯示層調整 — **無 API 呼叫、無自動追蹤/取消追蹤**，不違反 X 平台規則。

## 功能

- 🔴 **未回關高亮**：跟隨中頁，沒回關你的帳號用紅框圈起來
- 🔴 **未回跟高亮**：跟隨者頁，你沒回追的帳號用紅框圈起來
- 🏷️ **每列狀態標籤**：`互關`／`未回關 · 已監測 N 天`／`已回跟`／`未回跟`（全中文）
- 📊 **即時統計面板**：`未回關 N`／`總共 M · 互關 K`，不重複累計、只增不減
- 📅 **首次發現追蹤**：自動記錄每個未回關帳號第一次被發現的日期
- ⬆️ **智能排序**：未互關排最前、已互關排最後；只在列表頂部＋靜止時重排，捲動期間完全不碰 DOM（不卡頓、不空白）
- 🚫 **封鎖校正**：你拉黑某人後，自動把他從統計中剔除
- 🕵️ **本地取關偵測**：自動記下誰偷偷取消追蹤你，該列標 `剛取關你`／`曾取關 · 9/9`；資料只存自己的瀏覽器，不公開、不上傳

## 安裝

1. 瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/)
2. 打開 `GANSHA-Mutual-Radar.user.js` 的 Raw 頁面，或複製原始碼新增腳本
3. 到 `https://x.com/` 的 **跟隨中** / **跟隨者** 頁即可看到效果

## 使用

- 進 `/following`：未回關（他沒回關你）的排最前，紅框＋標籤標示
- 進 `/followers`：未回跟（你沒回追他）的排最前，紅框＋標籤標示；X 自己塞進來的推薦帳號標 `推薦 · 非粉絲`，不計入
- 進**別人的** `/followers`：不畫紅框，只標 `關注了你`／`已追蹤`／`互關`，「關注了你」的人排最前
- 往下捲載入更多 → 捲回頂部時會自動重新集中排序
- 右下角面板顯示累計統計與品牌標識
- 面板「`取關 N · 點此複製名單`」→ 查看／複製被取關紀錄（見下方章節）

## 本地取關偵測（v6.6+）

想知道「誰偷偷取消追蹤我」，不用一個一個點進去看，也不用把帳號交給任何第三方 App。

**怎麼做到的**

腳本每次掃描都記下「這個人當時有沒有追你」，下次再掃到同一個人時比對：

- 上次 **有追你** → 這次 **沒追你**，且「沒追你」的狀態**連續超過 30 分鐘** → 判定被取關
- 該列標上紅底白字 `剛取關你`（當天新偵測）或 `曾取關 · 9/9`（之前記過，附日期）
- 面板多一行 `取關 N · 點此複製名單`，點一下複製成清單（也可在 Console 執行 `__ganshaExportUnfollowers()`）

**為什麼要等 30 分鐘**

X 的「跟隨你」指示器是**分批渲染**的，列表剛載入時常常暫時讀不到。若當下就判定，會出現大量誤判——你會去質問一個其實沒取關你的人。30 分鐘寬限讓 DOM 載完後自動回補，誤判自己消失。

**已知限制**

- 屬**增量累積**：同一個人要被掃到兩次以上才會有紀錄；沒捲過、沒載入到的帳號不會計入
- 第一次掃到某人時只建立基準，當下無法判斷他是否剛取關
- 只偵測「他取消追蹤你」（跟隨中頁），不偵測你自己的主動操作

**隱私與合規**

- 資料全部存在**你自己的瀏覽器 localStorage**（`xufr_mstate_v1`、`xufr_unf_v1`），**不公開、不上傳、不傳送給任何人**
- 純讀取自己頁面上已顯示的公開資訊，**無 API 呼叫、無自動追蹤／取消追蹤**
- ⚠️ 請勿把偵測結果整理成公開名單發布。號召集體標記特定帳號違反 X 的 targeted harassment 與 platform manipulation 規則，且實務上被處分的往往是發起者，不是被點名者
